How CNNs Learn Emotional Action Units

Unlike traditional computer vision that relied on hand-crafted Gabor filters or SIFT descriptors, Convolutional Neural Networks (CNNs) automatically learn hierarchical spatial representations directly from raw pixel matrices:

  • Early Layers (Layers 1-2): Filter kernels learn localized primitives like edge orientations, skin luminance gradients, and contrast boundaries.
  • Mid-Level Layers (Layers 3-4): Assemble edges into anatomical motifs—eyebrow curvatures, nasolabial folds, pupil apertures, and lip corners.
  • Deep Layers & Dense Head: Combine motifs into global relational patterns that correspond to FACS Action Units, producing a 7-dimensional probability vector via Softmax.

The Mini-VGG Architecture for Emotion Detection

Optimized specifically for the FER-2013 dataset: compact footprint (~1.3M parameters), rapid CPU inference (<25ms), and high resistance to overfitting.

Block 1 Shape: 48 × 48
Low-Level Feature Block
  • Conv2D (32 filters, 3×3)
  • BatchNormalization
  • Conv2D (32 filters, 3×3)
  • MaxPooling2D (2×2 pool)
  • Dropout (0.25)
Block 2 Shape: 24 × 24
Mid-Level Motifs Block
  • Conv2D (64 filters, 3×3)
  • BatchNormalization
  • Conv2D (64 filters, 3×3)
  • MaxPooling2D (2×2 pool)
  • Dropout (0.25)
Block 3 Shape: 12 × 12
High-Level Action Units
  • Conv2D (128 filters, 3×3)
  • BatchNormalization
  • MaxPooling2D (2×2 pool)
  • Dropout (0.25)
Dense Head Output: 7 Probs
Classification Head
  • Flatten (4,608 vector)
  • Dense (256 units + ReLU)
  • BatchNormalization
  • Dropout (0.50 rate)
  • Dense(7, Softmax)

Complete Python Training Script (train.py)

Clean, simple, copy-pasteable script to train and save your own .h5 model file.

train_emotion_model.py Python 3.11 
# =============================================================================
# 1. IMPORT REQUIRED LIBRARIES
# =============================================================================
import os
import numpy as np
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Conv2D, MaxPooling2D, Flatten, Dense, Dropout, BatchNormalization
from tensorflow.keras.optimizers import Adam
from tensorflow.keras.preprocessing.image import ImageDataGenerator
from tensorflow.keras.callbacks import ModelCheckpoint, ReduceLROnPlateau, EarlyStopping

# 7 Target Emotion Classes
EMOTIONS = ['Angry', 'Disgust', 'Fear', 'Happy', 'Neutral', 'Sad', 'Surprise']

# =============================================================================
# 2. DEFINE THE CNN ARCHITECTURE
# =============================================================================
def build_emotion_cnn(input_shape=(48, 48, 1), num_classes=7):
    model = Sequential([
        # Block 1
        Conv2D(32, (3, 3), activation='relu', padding='same', input_shape=input_shape),
        BatchNormalization(),
        Conv2D(32, (3, 3), activation='relu', padding='same'),
        BatchNormalization(),
        MaxPooling2D(pool_size=(2, 2)),
        Dropout(0.25),

        # Block 2
        Conv2D(64, (3, 3), activation='relu', padding='same'),
        BatchNormalization(),
        Conv2D(64, (3, 3), activation='relu', padding='same'),
        BatchNormalization(),
        MaxPooling2D(pool_size=(2, 2)),
        Dropout(0.25),

        # Block 3
        Conv2D(128, (3, 3), activation='relu', padding='same'),
        BatchNormalization(),
        MaxPooling2D(pool_size=(2, 2)),
        Dropout(0.25),

        # Fully Connected Classification Head
        Flatten(),
        Dense(256, activation='relu'),
        BatchNormalization(),
        Dropout(0.5),
        Dense(num_classes, activation='softmax')
    ])
    
    model.compile(
        optimizer=Adam(learning_rate=0.001),
        loss='categorical_crossentropy',
        metrics=['accuracy']
    )
    return model

# =============================================================================
# 3. DATA AUGMENTATION & TRAINING PIPELINE
# =============================================================================
if __name__ == '__main__':
    print("Building Emotion CNN Model...")
    model = build_emotion_cnn()
    model.summary()

    # Data augmentation generator for training
    train_datagen = ImageDataGenerator(
        rescale=1.0 / 255.0,
        rotation_range=15,
        width_shift_range=0.1,
        height_shift_range=0.1,
        shear_range=0.1,
        zoom_range=0.1,
        horizontal_flip=True,
        fill_mode='nearest'
    )

    # Set directories where your dataset is extracted:
    # Directory structure: data/train/happy/, data/train/sad/, etc.
    TRAIN_DIR = "data/train"
    VAL_DIR = "data/test"

    if os.path.exists(TRAIN_DIR):
        train_generator = train_datagen.flow_from_directory(
            TRAIN_DIR,
            target_size=(48, 48),
            color_mode='grayscale',
            batch_size=64,
            class_mode='categorical'
        )

        # Save best model to uploads/models/ folder directly!
        save_path = "uploads/models/my_emotion_model.h5"
        checkpoint = ModelCheckpoint(save_path, monitor='val_accuracy', save_best_only=True, verbose=1)
        lr_reducer = ReduceLROnPlateau(monitor='val_loss', factor=0.5, patience=3, min_lr=1e-6, verbose=1)
        early_stop = EarlyStopping(monitor='val_loss', patience=8, restore_best_weights=True)

        print("Starting model training for 30 epochs...")
        model.fit(
            train_generator,
            epochs=30,
            callbacks=[checkpoint, lr_reducer, early_stop]
        )
        print(f"🎉 Model trained and saved to {save_path}!")
    else:
        print("[INFO] Dataset folder not found. Please provide the path to your FER-2013 data directory.")

Hyperparameter Tuning & Optimization Cheatsheet

Parameter Recommended Value Rationale & Impact on Emotion Detection
Batch Size 64 Provides balanced gradient estimates while fitting comfortably into 4GB+ GPU VRAM.
Initial Learning Rate 1e-3 (0.001) with Adam Swift convergence on early conv filters; decaying by 50% on plateaus prevents oscillation.
Dropout Rates 0.25 (Conv) • 0.50 (Dense) Crucial for FER-2013 to stop the network from memorizing individual face identities.
Class Weights Inverse frequency weighting Disgust only accounts for ~1.5% of FER-2013 samples. Weighting prevents disgust starvation.
Face Alignment Padding 8% - 10% border expansion Ensures chin and forehead landmarks are not clipped by aggressive face detectors.
